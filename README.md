# Radio BIDAR Banner Editor

یک سایت استاتیک برای GitHub Pages با قابلیت:
- Edit و ویرایش عنوان برنامه، نام فرد، شماره اپیزود، تاریخ و ساعت
- آپلود عکس گوینده
- عکس گوینده به صورت مربع 1:1 در بخش بالای نام نمایش داده می‌شود
- خروجی PNG در اندازه‌های 1200×1200، 1080×1080 و 1024×1024
- بدون نیاز به سرور یا دیتابیس

## عکس گوینده
بهترین اندازه: **1200×1200 px** (نسبت 1:1).
سر و شانه‌ها را در مرکز تصویر قرار دهید.

## اجرا روی GitHub Pages
1. این فایل‌ها را در یک repository قرار دهید.
2. از Settings → Pages، گزینه Deploy from branch را فعال کنید.
3. Branch اصلی و پوشه `/root` را انتخاب کنید.
4. فایل `index.html` صفحه اصلی خواهد بود.

## نکته
فونت Vazirmatn از Google Fonts بارگذاری می‌شود؛ در صورت قطع اینترنت، مرورگر از Tahoma/Arial به عنوان جایگزین استفاده می‌کند.
